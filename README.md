# Андрей Скиба — сайт-визитка

Многостраничный сайт-портфолио журналиста Андрея Скибы.

## Структура

- `index.html` — главная
- `about.html` — биография и образование
- `work.html` — направления работы
- `articles.html` — публикации
- `style.css` — адаптивный дизайн
- `script.js` — мобильное меню и fallback для фото

## Фото

Для использования фотографии из исходного сообщения сохраните её в корне репозитория под именем **`andrey-skiba.jpg`**. Пока файла нет, сайт автоматически показывает `avatar.svg`.

## Публикации

Страница автора: https://ng.kz/authors/andrey-skiba

## GitHub Pages

В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. После сохранения GitHub Pages опубликует сайт.
